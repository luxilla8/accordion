Accordion

A small, accessible accordion with no dependencies. It is built on the browser's own <details> element, so it works before the script loads, and the script adds the rest.

FixIt finally opens

The 2018 version never expanded a panel. It looked panels up with a class name that started with a dot, so the browser searched for a class literally called .accordion-panel and found nothing. Every click then failed on panel.style.

- var panel = document.getElementsByClassName(".accordion-panel");
- panel.style.maxHeight = panel.scrollHeight + "px";
+ <details>
+   <summary>Question</summary>
+   <div>Answer</div>
+ </details>

Version 2 doesn't look anything up. Each panel sits inside its own <details>, so there's nothing to get wrong.

AccessScreen readers know what it is

A <summary> is announced as a button that reports whether it's expanded or collapsed. The browser keeps that state in sync, so there are no ARIA attributes to drift out of date.

The original used plain buttons with no state, so a screen reader user heard "accordion-control 1, button" and nothing about what it controlled.

AccessBuilt for the keyboard

Tab reaches every header, and Enter or Space toggles it. Inside a group, ↑ ↓ move between headers and Home End jump to the first and last, following the WAI-ARIA Authoring Practices accordion pattern.

MotionAnimation that can change its mind

Heights animate with the Web Animations API, measured from the real content instead of a guessed max-height. Click a header twice quickly and the panel reverses from wherever it is. Longer panels take a little longer.

Six presets set the feel. Spring uses a real damped-spring curve with a slight overshoot. Cascade brings each paragraph in one after another, like this one. Blur pulls the content into focus. Pick one above and it replays here.

If your system asks for reduced motion, every preset opens and closes instantly.

SturdyWorks before the JavaScript loads

Without the script, every item still opens and closes, and the native name attribute keeps only one open at a time. In Chromium browsers, find in page (Ctrl/⌘ F) opens the section that holds the match.

Items added later, by a framework or by hand, are picked up automatically.

SturdyEvery section has an address

Give an item an id and a link to #that-id opens it and scrolls it into view. Try it: open the animation section.

Use it

Copy two files into your project. No build step.

<!-- in <head> -->
<link rel="stylesheet" href="accordion.css">
<script src="accordion.js" defer></script>

<!-- anywhere -->
<accordion-group>
  <details id="shipping" name="faq">
    <summary>How long does shipping take?</summary>
    <div>Three to five working days.</div>
  </details>
  <details id="returns" name="faq">
    <summary>Can I return an order?</summary>
    <div>Yes, within 30 days.</div>
  </details>
</accordion-group>

Reference

Attributes
AttributeEffect
multipleLets several items stay open. Without it, opening one closes the others.
animationMotion preset: slide (default), spring, cascade, blur, fade or none. Also accepts your own presets.
durationFixed animation length in milliseconds. By default it scales with the panel's height.
easingAny CSS easing, such as ease-in-out, steps(4) or a linear() curve. Replaces the preset's easing.
open on <details>Starts that item open.
name on <details>Optional. Keeps the group one-at-a-time before the script loads.
Methods
MethodEffect
open(item)Opens an item. item can be the element, its index, or its id.
close(item)Closes an item.
toggle(item, force?)Flips an item, or sets it when force is given.
openAll()Opens every item, even in one-at-a-time mode.
closeAll()Closes every item.
isOpen(item)Where the item is heading, counting animations in progress.
itemsThe group's <details> elements. Nested groups are excluded.
Events

accordion-toggle fires on the group as soon as an item starts to open or close. It bubbles, and event.detail holds { item, open, index }.

group.addEventListener('accordion-toggle', (event) => {
  const { item, open } = event.detail;
  analytics.track(open ? 'faq_open' : 'faq_close', { id: item.id });
});
Custom motion

Register a preset once, then use it by name. enter runs for each panel as it opens. It receives the timing to use and returns the animations it starts. duration and easing are optional and control the height.

AccordionGroup.animations.pop = {
  easing: 'cubic-bezier(.3, 1.4, .6, 1)',
  duration: (distance) => 300 + distance * 0.3,
  enter: (panel, timing) => panel.animate(
    { opacity: [0, 1], scale: [0.92, 1] },
    timing,
  ),
};
<accordion-group animation="pop">…</accordion-group>

Closing always fades the content out, and an interrupted animation always reverses from where it is, whatever preset is active.

Styling

Override these custom properties on the group or any ancestor. Everything else is plain CSS you can restyle freely.

accordion-group {
  --accordion-border: #e3dfe6;
  --accordion-hover: #f4f1f6;
  --accordion-accent: #c2477a;
  --accordion-padding-block: 1rem;
  --accordion-padding-inline: 1.25rem;
}

Each item carries data-state="open" or "closed". It flips the moment a close begins, which is what the chevron uses.
